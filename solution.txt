Solution Explanation:

This solution generates all consecutive substrings of a given string by using two nested loops.

The outer loop starts at each character in the string.
The inner loop builds substrings starting from that character by adding one character at a time.

Example:
Input: "abc"
Output: ["a", "ab", "abc", "b", "bc", "c"]

Approach:
- Start at index 0 → build: a, ab, abc
- Move to index 1 → build: b, bc
- Move to index 2 → build: c

This ensures all consecutive substrings are captured in order.

Time Complexity:

The outer loop runs n times.
The inner loop runs up to n times for each iteration.

Therefore, the time complexity is:

O(n²)

Space Complexity:
O(n²) because we store all substrings.
